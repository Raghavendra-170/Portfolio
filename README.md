👨‍💻 Personal Portfolio Website

A dynamic and responsive personal portfolio website showcasing my projects, skills, certifications, and contact information. Built with HTML, CSS, and Bootstrap, this website helps visitors learn more about my technical background and experience in web development.

🌐 Live Site

🔗 Visit Portfolio Website https://raghavendra-protfolio.netlify.app/
📦 GitHub Repository https://github.com/Raghavendra-170/Portfolio.git

 🎯 Features

- 📄 **About Me** section with education, strengths, and background
- 🧠 **Skills** categorized by frontend, backend, and tools
- 💼 **Project Showcase** with links to GitHub and live demos
- 📜 **Certifications** earned from platforms like Coursera, Cisco, and HackerRank
- 📬 **Contact Section** with email and social links
- 💡 **Admin-editable UI** structure for easier content updates
- 📱 **Fully Responsive** design using Bootstrap and custom CSS

🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Deployment:** Netlify
- **Version Control:** Git & GitHub
